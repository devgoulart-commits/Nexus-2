Banco de Dados (PostgreSQL / Neon)

Desconectado

O Nexus Escolar se conecta a um banco PostgreSQL real hospedado no Neon, através da API própria do sistema (pasta /api). Não é preciso colar nenhuma senha aqui — a conexão é feita pelo servidor.

Esquema SQL em schema.sql e instruções de publicação em DEPLOY.md. Alunos, Professores, Turmas, Mensalidades, Despesas e PDV já leem e gravam direto no banco.
